# Concepts

Where the mark came from. Nothing here is packed or published — the shipped assets are
generated by [`../generate.py`](../generate.py), and that script is the source of truth.

| File | What it is |
|---|---|
| `portico-mark-concept.png` | The original generated concept, 1254×1254. The palette and proportions in `generate.py` were measured out of this image. |

It is kept because a mark without its concept is hard to revisit: the next person who wants to
know whether the chamfers were deliberate has something to look at. It is **not** a source file —
editing it changes nothing.
